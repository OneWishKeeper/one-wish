ONE WISH WEBSITE

FILES INCLUDED
- index.html
- style.css
- script.js

UPLOAD TO GITHUB
1. In your GitHub repository, open the Upload file page.
2. Upload index.html, style.css, and script.js.
3. Keep "Commit directly to the main branch" selected.
4. Tap "Commit changes."
5. Wait about 1 to 5 minutes.
6. Open:
   https://onewishkeeper.github.io/one-wish/

IMPORTANT
The "Seek the Sorcerer" button currently contains:
REPLACE-WITH-YOUR-EMAIL

We will replace that later with the contact email you choose.

This starter version does not save wishes yet. It only displays the experience on the visitor's device.
